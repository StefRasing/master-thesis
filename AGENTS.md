# Paper-writing chats

These instructions apply to AAAI-27 manuscript work in forks of the paper-planning chat.

When responding in a paper-writing fork for the first time, rename the current chat before starting manuscript work as soon as its scope is clear. Use the Codex `set_thread_title` action with no thread ID so the action targets your own chat. Verify the returned title.

- For paper-wide work, use `0 Topic`.
- For work on one chapter or section, use its index from the agreed outline followed by the section title, such as `2 Methods`. If the index is still undecided, resolve it from the outline or with the user before choosing a number.
